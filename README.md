# Influency - Influencer & Agency Website Template

HTML Codex(#3959)의 **Influency** 인플루언서 마케팅 & 에이전시 반응형 웹사이트 템플릿입니다.

## 🎨 Design & Palette
- **Primary Color**: `#B9A0FC` (Pastel Lavender)
- **Secondary Color**: `#FCE2A0` (Pastel Peach / Yellow)
- **Fonts**:
  - `Dancing Script` (Accent cursive)
  - `Playfair Display` (Headings serif)
  - `Work Sans` (Body text)

## 📁 Directory Structure
```text
influency/
├── index.html                    # 메인 랜딩 페이지
├── css/
│   ├── bootstrap.min.css         # 전용 커스텀 부트스트랩
│   └── style.css                 # 템플릿 스타일시트
├── js/
│   └── main.js                   # 인터랙션 스크립트
├── img/                          # 로고, 인플루언서 사진, 배경 패턴 등
└── lib/                          # WOW.js, Owl Carousel, CounterUp 등 라이브러리
```

## 🚀 Key Features
- **Topbar & Floating Pill Navbar**: 상단 연락처 정보 및 스크롤 시 상단 고정(Sticky) 둥근 네비게이션 바
- **Tilted Hero Cards**: 각도가 살짝 기울어진 감각적인 인플루언서 프로필 카드 & 호버 액션
- **Stats Counter**: 좌우 2색 분할 배경 위의 실시간 숫자 카운트업
- **Services Grid**: 호버 시 회전하는 아이콘 뱃지가 포함된 8개 서비스 카드
- **Work Process**: 대형 숫자(01, 02, 03)와 점선으로 연결된 3단계 프로세스
- **Pricing & Registration**: 3단 가격 플랜 비교 및 크리에이터 등록 배너
- **Creator Showcase & Testimonials**: 소셜 플랫폼 팔로워 뱃지 프로필 및 고객 후기 캐러셀
